# Порты

## Карта портов

| Порт | Сервис | Доступ | Примечание |
|------|--------|--------|------------|
| 22 | sshd | публичный | системный |
| 21 | vsftpd | публичный | FTP |
| 40000–40100 | vsftpd (passive) | публичный | задать в `vsftpd.conf` |
| 443 | xray | публичный | **сторонний, не трогаем** |
| 2053, 2096 | x-ui | публичный | сторонний |
| 11111, 62789 | xray (loopback) | 127.0.0.1 | сторонний |
| 40059 | containerd (loopback) | 127.0.0.1 | системный |
| 53 | systemd-resolve | loopback | системный |
| 3306 | MariaDB (Ф3) | 127.0.0.1 | будет добавлен |
| — | whisper CLI (Ф2) | без порта | subprocess |
| — | бот (long polling) | без входящего порта | исходящие к api.telegram.org |

## Принципы

- Бот **не открывает** входящих портов — long polling.
- whisper — **CLI**, не сервер, порт не нужен.
- MariaDB слушает только loopback.
- xray/x-ui — сторонние сервисы, **не трогаем**.
- nginx/сайт — отложены (443 занят xray).
